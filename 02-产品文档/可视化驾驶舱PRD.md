## 1. 业务背景与使用角色
### 1.1 业务背景
- 模块定位：为监管值守和汇报场景提供道路资源、测试示范申请、车辆运行、异常事件和事故趋势的集中态势视图。
- 关联模块：引用开放道路管理、测试示范监管、车辆状态监控、异常状态事件和监测数据分析的数据；驾驶舱不替代原业务页面的办理能力。
### 1.2 使用角色
| 角色 | 该模块中的职责 | 客户端 |
| --- | --- | --- |
| 监管值守人员 | 查看全域态势、关注异常、定位区域 | 驾驶舱 |
| 管理汇报人员 | 查看资源、运行及事故趋势 | 驾驶舱 |
### 1.3 核心目标与价值
| 目标维度 | 说明 |
| --- | --- |
| 态势感知 | 在同一视图理解道路、申请、车辆、异常与事故情况 |
| 快速研判 | 指标切换后查看对应构成，区域选择后查看区域摘要 |
| 业务隔离 | 驾驶舱与 WEB 管理端独立呈现，不改变原有业务页面 |

## 3. 功能详细设计
### 3.1 F01 全域态势总览
#### 3.1.1 功能目标与范围
| 项目 | 说明 |
| --- | --- |
| 功能目标 | 值守人员快速掌握全市智能网联汽车运行态势 |
| 使用角色 | 监管值守人员、管理汇报人员 |
| 触发条件 | 打开驾驶舱首页 |
| 功能边界 | 展示聚合信息，不在驾驶舱办理审批、处置和配置 |
| 成功结果 | 页面呈现最新可用的各模块概况与更新时间 |
#### 3.1.3 数据与字段规则
| 字段 | 业务含义 | 数据来源 | 格式/口径规则 | 空值处理 |
| --- | --- | --- | --- | --- |
| 路段总数、开放路段、暂停路段 | 道路资源规模及开放状态 | 开放道路管理 | 以所选统计范围内有效路段计数 | 无数据展示“--” |
| 道路测试、示范应用、商业化试点 | 各业务申请量 | 准入申请 | 按申请业务类型计数 | 无数据展示“--” |
| 车辆总数、在线车辆、累计里程 | 车辆运行规模 | 车辆状态监控 | 在线以最近一次有效状态为准，里程单位由数据源提供 | 无数据展示“--” |
| 事件总数、预警事件、告警事件 | 异常事件数量 | 异常状态事件 | 预警与告警按事件分类计数 | 无数据展示“--” |
| 实时事件 | 最近异常事件的车辆、类型、时间 | 异常状态事件 | 按发生时间倒序 | 暂无事件时展示空状态 |
| 事故趋势 | 统计周期内事故数量变化 | 监测数据分析 | 按时间序列展示 | 暂无数据时不绘制假趋势 |
**异常信息模块呈现：** 异常事件统计图表与实时事件列表在同一模块容器内连续呈现，统计图表位于上方，实时事件列表位于下方；两者使用内部弱分隔保持层级，不额外展示“异常事件统计 / 实时事件”组合说明。
#### 3.1.5 交互流程
1. 用户打开首页，系统加载全域聚合数据及数据更新时间。
2. 加载成功后展示道路、申请、车辆、异常、事故和地图信息；单模块失败仅显示该模块错误，保留其他模块可用。
3. 数据延迟或连接中断时保留最近有效数据并显示对应状态；无权限时不暴露受限数据。
### 3.2 F02 指标构成切换
#### 3.2.1 功能目标与范围
| 项目 | 说明 |
| --- | --- |
| 功能目标 | 在同一业务模块内切换关注指标并查看关联构成 |
| 使用角色 | 可查看该业务模块的驾驶舱用户 |
| 触发条件 | 选择申请、车辆或异常模块的指标，或选中开放道路资源模块并选择路段统计指标 |
| 功能边界 | 切换仅影响所属业务模块，不改变其他模块统计口径 |
| 成功结果 | 被选指标和关联构成图同步更新，其他模块保持原状态 |
#### 3.2.4 业务规则与状态变化
| 规则编号 | 触发条件 | 业务规则 | 数据/状态变化 |
| --- | --- | --- | --- |
| R01 | 选择指标 | 同一模块仅有一个当前选中项 | 更新选中指标与图表中心摘要 |
| R02 | 统计范围变化 | 只作用于所属模块 | 更新该模块指标与图表，不影响其他模块 |
| R03 | 选中开放道路资源模块 | 地图切换为道路资源视图，按区域展示路段数量聚合，并隐藏车辆与实时轨迹图层 | 更新地图业务视图和道路资源模块选中状态 |
| R04 | 选择路段统计指标 | 路段总数、开放路段、暂停路段为互斥筛选项 | 地图聚合数量及路段矢量仅展示对应筛选范围 |
| R05 | 地图缩放级别达到路段展示级别 | 道路资源视图自动取消区域聚合并展示当前筛选范围内的路段矢量；低于该级别时恢复区域聚合 | 地图在区域聚合与路段矢量之间切换，当前筛选条件保持 |
| R06 | 选中车辆实时监控模块 | 地图切换为车辆视图，按区域展示车辆数量聚合，并隐藏道路资源图层 | 更新地图业务视图和车辆实时监控模块选中状态 |
| R07 | 选择车辆总数、在线车辆或累计里程 | 三项为互斥筛选项；在线车辆仅统计非离线车辆，累计里程仅展示存在有效里程的车辆 | 更新车辆区域聚合数量、车辆点位范围和车辆图例，其他模块保持原状态 |
| R08 | 地图缩放级别达到车辆展示级别，或用户点击车辆区域聚合 | 车辆视图取消区域聚合并展示当前筛选范围内的具体车辆位置；车辆点位可查看车辆状态和里程摘要 | 地图切换至车辆点位视图，当前车辆筛选条件保持 |
| R09 | 地图缩放级别低于车辆展示级别 | 车辆视图恢复区域车辆数量聚合 | 地图恢复区域聚合，当前车辆筛选条件保持 |
| R15 | 选中异常事件统计模块 | 地图切换为异常事件视图，按当前统计时间范围和事件分类统计各区域异常事件量 | 隐藏车辆总览、道路及实时轨迹图层，展示异常事件区域聚合 |
| R16 | 切换异常事件统计时间范围 | 事件总数、预警事件、告警事件及地图聚合统一使用当前时间范围 | 更新异常事件指标、构成图和地图聚合数量 |
| R17 | 选择事件总数、预警事件或告警事件 | 三项为互斥筛选项；预警和告警按事件分类过滤，事件总数展示全部分类 | 更新地图区域聚合及车辆点位范围 |
| R18 | 地图缩放级别达到车辆展示级别，或用户点击异常事件区域聚合 | 异常事件视图取消区域聚合并展示存在匹配事件的车辆位置；车辆图标显示匹配事件数量角标 | 车辆按事件状态聚合为未完成或已完成并更新图例 |
| R19 | 车辆存在多个匹配事件 | 只要任一匹配事件状态为待处理、待审核或已退回，车辆归为未完成；仅当全部匹配事件状态为已完成时归为已完成 | 车辆颜色、图例和信息窗状态保持一致 |
#### 3.2.5 交互流程
1. 用户选择某模块的指标，系统将该项设为当前口径。
2. 系统更新关联构成和中心摘要，并保持模块占用空间不变。
3. 选中车辆实时监控模块或切换车辆指标时，系统同步刷新车辆区域聚合或车辆点位，并按人工驾驶、自动驾驶、离线展示状态图例。
4. 无可用构成数据时展示无数据状态，不以全零图表代替。
### 3.3 F03 区域下钻摘要
#### 3.3.1 功能目标与范围
| 项目 | 说明 |
| --- | --- |
| 功能目标 | 快速查看地图区域内车辆位置与状态，或查看开放道路资源的路段空间分布 |
| 使用角色 | 可查看对应区域数据的驾驶舱用户 |
| 触发条件 | 选择车辆区域聚合标记，或在道路资源视图中选择道路区域聚合标记 |
| 功能边界 | 车辆视图展示当前筛选范围内的区域聚合和具体车辆位置；道路资源视图展示当前筛选范围内的路段矢量及状态信息，不在驾驶舱办理道路业务 |
| 成功结果 | 车辆视图展示区域车辆数量聚合，放大或点击聚合后展示车辆位置、状态和里程；道路资源视图展示当前筛选范围内的路段矢量、道路名称、长度、车道数和开放状态 |
#### 3.3.5 交互流程
1. 用户点击车辆区域聚合或道路资源区域聚合，系统读取该区域聚合信息。
2. 车辆视图放大地图至车辆展示级别并展示当前筛选范围内的车辆位置；道路资源视图放大至该区域并展示当前筛选范围内的路段矢量。
3. 用户点击车辆位置可查看车辆状态和累计里程；点击道路矢量可查看道路名称、区域、长度、车道数和开放状态；数据不足时展示可用字段和缺失提示。
4. 用户缩小地图后，车辆视图自动恢复区域聚合；道路资源视图自动恢复区域聚合标记。
### 3.4 F04 地图图层
#### 3.4.1 功能目标与范围
| 项目 | 说明 |
| --- | --- |
| 功能目标 | 控制地图业务图层的显示与隐藏 |
| 使用角色 | 驾驶舱用户 |
| 触发条件 | 选择地图图层控制 |
| 功能边界 | 仅改变当前驾驶舱地图的显示状态 |
| 成功结果 | 地图图层状态更新，业务数据不改变 |
#### 3.4.3 数据与字段规则
| 字段 | 业务含义 | 数据来源 | 格式/口径规则 | 空值处理 |
| --- | --- | --- | --- | --- |
| 地图中心、缩放级别 | 当前地图视野状态 | 地图服务与驾驶舱配置 | 页面打开时使用默认全域视角，用户缩放或拖拽后保留当前视野 | 无法读取视野时恢复默认全域视角 |
| 行政区边界、测试车辆、异常事件、实时轨迹、开放道路 | 地图业务图层 | 关联业务模块 | 各图层独立控制显隐；异常事件按当前时间范围和事件分类筛选，开放道路按道路状态展示并受道路资源模块筛选条件影响 | 图层无数据时保留图层控制项并展示空状态 |
#### 3.4.5 交互流程
1. 用户打开驾驶舱，系统加载默认全域地图视野及可用业务图层。
2. 用户缩放或拖拽地图，系统更新当前视野并保持业务图层与点位相对位置一致。
3. 用户执行地图图层操作，系统切换对应图层显隐。
4. 用户选中开放道路资源模块，系统切换道路资源地图视图，并按当前路段筛选指标展示区域聚合。
5. 用户选中异常事件统计模块，系统切换异常事件地图视图，并按当前时间范围和事件分类展示区域异常事件聚合。
6. 用户选择车辆或异常事件区域聚合标记，系统放大地图并展示当前筛选范围内的车辆位置；异常车辆图标展示事件数量及未完成/已完成状态，缩小地图后自动恢复区域聚合。
7. 地图或图层加载失败时，保留其他驾驶舱模块可用，并展示地图不可用提示。
### 3.5 F05 道路列表浮层
#### 3.5.1 功能目标与范围
| 项目 | 说明 |
| --- | --- |
| 功能目标 | 在驾驶舱内快速查看道路资源清单及开放状态分布 |
| 使用角色 | 监管值守人员、管理汇报人员 |
| 触发条件 | 用户点击开放道路资源标题后的道路列表入口 |
| 功能边界 | 仅提供道路资源查看、状态筛选与区域筛选，不在浮层内办理道路建档、编辑或状态管控 |
| 成功结果 | 系统展示道路清单及路段总数、开放道路、暂停道路统计，用户可按统计项和所属区域筛选清单，并按页查看道路 |
#### 3.5.3 数据与字段规则
| 字段 | 业务含义 | 数据来源 | 格式/口径规则 | 空值处理 |
| --- | --- | --- | --- | --- |
| 路段总数 | 当前道路资源范围内的有效路段总量 | 开放道路管理 | 统计全部有效路段 | 无数据展示“--” |
| 开放道路 | 当前道路资源范围内处于开放状态的路段数量 | 开放道路管理 | 仅统计开放状态路段 | 无数据展示“--” |
| 暂停道路 | 当前道路资源范围内处于暂停状态的路段数量 | 开放道路管理 | 仅统计暂停状态路段 | 无数据展示“--” |
| 道路清单字段 | 道路名称、所属区域、道路等级、车道数、开放状态、开放时段、适用业务场景 | 开放道路管理 | 按道路资源管理模块字段口径展示；开放状态枚举为开放、暂停 | 缺失字段展示“--” |
| 适用业务场景 | 道路支持的无人化业务场景 | 开放道路管理 | 枚举为无人环卫、无人物流、无人出行、无人公交；单条道路可同时支持多个场景 | 无场景数据时展示“--” |
| 所属区域筛选 | 按行政区缩小道路清单范围 | 开放道路管理 | 选项为全部区域及当前道路资源范围内的区域，与道路状态筛选叠加生效 | 无匹配结果时展示空结果提示 |
| 列表分页 | 道路清单每页展示数量及当前页码 | 驾驶舱配置 | 每页 10 条，展示结果总数、页码与翻页操作；筛选条件变化后回到第一页 | 无数据时列表展示空结果提示 |
#### 3.5.4 业务规则与状态变化
| 规则编号 | 触发条件 | 业务规则 | 数据/状态变化 |
| --- | --- | --- | --- |
| R10 | 打开道路列表浮层 | 默认展示全部有效路段，路段总数为当前选中统计口径，所属区域为全部区域，列表回到第一页 | 浮层打开并展示第一页道路清单 |
| R11 | 点击路段总数、开放道路或暂停道路统计 | 三项为互斥筛选项；开放道路仅展示开放状态路段，暂停道路仅展示暂停状态路段 | 更新当前筛选项和道路清单结果 |
| R12 | 在浮层内切换道路状态筛选 | 道路列表筛选与道路资源模块当前筛选口径保持同步 | 同步更新模块指标选中状态；道路地图处于道路视图时同步更新地图道路范围 |
| R13 | 选择所属区域下拉筛选 | 区域筛选与道路状态筛选叠加生效，仅展示同时满足两个条件的路段 | 更新清单结果并回到第一页 |
| R14 | 切换页码 | 筛选条件变化后回到第一页；当前页码超出结果总页数时收敛到最后一页，结果不足一页时仅展示单页且翻页不可用 | 更新当前页道路清单与页码状态 |
#### 3.5.5 交互流程
1. 用户点击开放道路资源标题后的道路列表入口。
2. 系统加载当前道路资源范围内的统计数据和道路清单，默认选中路段总数、所属区域为全部区域并展示第一页。
3. 用户点击路段总数、开放道路或暂停道路统计项，或在所属区域下拉中选择区域。
4. 系统按所选统计项与区域叠加刷新列表并回到第一页，列表按每页 10 条分页展示，用户可翻页查看其余道路。
5. 筛选项无匹配数据时展示空结果提示，其他统计项和区域筛选保持可用。
6. 用户点击浮层底部的关闭按钮后返回驾驶舱，已选道路筛选口径保留。
#### 3.5.6 异常处理
| 异常场景 | 触发条件 | 系统处理 | 用户反馈 | 恢复方式 |
| --- | --- | --- | --- | --- |
| 道路数据加载失败 | 无法读取道路资源数据 | 保留驾驶舱其他模块，列表区域不展示旧数据 | 提示道路列表暂不可用 | 关闭浮层后重新打开 |
| 筛选无结果 | 所选状态或区域下没有匹配路段 | 保留统计项、区域筛选和筛选状态，列表展示无结果提示 | 提示当前筛选条件下暂无道路 | 切换其他统计项或所属区域 |

## 4. 业务规则汇总
### 4.1 数据口径与联动规则
| 触发字段 | 触发条件 | 联动行为 |
| --- | --- | --- |
| 业务模块指标 | 选择另一指标 | 仅更新本模块构成、摘要和选中状态；开放道路资源指标同时筛选地图道路 |
| 统计范围 | 选择时间范围 | 仅重算本模块当前指标与构成 |
| 地图区域 | 选择区域聚合 | 车辆视图放大至该区域并展示当前筛选范围内的车辆位置；道路资源视图放大至该区域并展示当前筛选范围内的路段矢量，缩小地图后恢复区域聚合，不改变全域累计数据 |
| 道路列表筛选 | 点击路段总数、开放道路或暂停道路统计，或选择所属区域 | 列表按状态与区域叠加筛选并回到第一页；道路地图处于道路视图时同步更新道路范围，关闭浮层后保留当前口径 |
### 4.2 数据状态规则
- 单模块加载、无数据、失败、延迟和权限受限相互区分；故障不影响其他模块。
- 实时数据应展示最近有效更新时间；演示原型不以模拟时钟充当真实业务刷新证明。
