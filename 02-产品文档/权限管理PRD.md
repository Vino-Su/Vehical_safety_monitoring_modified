## 名词解释

| 名词/缩写 | 解释 |
| ---------- | ---- |
| RBAC | 基于角色的访问控制模型:用户绑定角色,角色挂载权限,用户不直接持有权限 |
| 功能权限 | 控制用户"能不能操作"的权限,包含菜单权限(能否进入页面)、按钮权限(能否执行页面内操作)、接口权限(后端能否放行请求) |
| 数据权限 | 控制用户"能看到哪些数据"的权限,以数据范围规则形式生效于各业务列表与统计 |
| 权限资源 | 被授权的客体对象,由各业务应用上报至权限中心统一维护,分为菜单、按钮、接口三类 |
| 权限中心 | 本模块的定位:集中接收、维护、分发权限资源与授权关系的平台级服务 |
| 系统内置角色 | 系统预置、不可编辑和删除的角色,如超级管理员、只读观察员 |
| 数据范围 | 数据权限的生效粒度,如仅本人、本部门、本部门及下级、指定多个部门、全部数据 |

## 1. 业务背景与使用角色

### 1.1 业务背景
- 模块定位:权限管理模块是智能网联汽车安全监测平台的**基础支撑模块**,承担平台账号体系、组织架构、角色与权限资源、数据权限的集中管理,回答"谁能进平台、属于哪个组织、能做什么、能看到哪些数据"四个问题
- 核心特点:采用RBAC模型,用户不直接分配权限只分配角色;功能权限与数据权限分离,功能权限控制"能不能点",数据权限控制"能看到哪些数据";权限资源由各业务应用上报,产品侧统一维护
- 关联模块关系:权限校验能力被平台全部业务模块(测试示范监管、开放道路资源管理、监测数据分析等)消费;全部权限变更操作写入平台管理模块的操作日志;组织架构为用户归属与数据权限过滤提供基准
- 建设必要性:平台角色多(企业用户、第三方专业服务机构、市工作专班、交通管理部门、公众访客、系统管理员),此前角色页面访问范围硬编码于前端配置,需要通过权限管理实现配置化管控与审计追溯

### 1.2 使用角色

| 角色 | 该模块中的职责 | 客户端 |
| ---- | ------------ | ------ |
| 系统管理员 | 维护账号用户、组织架构、角色与授权、权限资源、数据权限的全部配置 | Web管理端 |
| 各业务应用/模块 | 将本应用的菜单、按钮、接口权限资源上报至权限中心 | 服务端 |
| 全部登录用户 | 登录后按所绑定角色动态获得菜单、操作与数据可见范围 | Web管理端/公开端 |

### 1.3 核心目标与价值

| 目标维度 | 说明 |
| -------- | ---- |
| 权限集中管控 | 账号、组织、角色、权限资源、数据权限统一管理,避免各模块分散维护 |
| 最小权限原则 | 按角色批量授权,用户仅通过角色获得权限,权限变更可快速回收 |
| 灵活的数据隔离 | 同一功能页面下按数据范围过滤,满足多部门、多主体数据隔离要求 |
| 变更可追溯 | 权限的新增、修改、删除、授权调整全部写入操作日志,支撑安全审计 |

## 3. 功能详细设计

### 3.1 F01 账号用户管理

#### 3.1.1 功能目标与范围

| 项目 | 说明 |
| ---- | ---- |
| 功能目标 | 管理平台账号从创建、使用到冻结的完整生命周期,并完成账号与组织、角色的绑定 |
| 使用角色 | 系统管理员 |
| 触发条件 | 新人员入职需开通账号、账号信息变化需维护、账号存在安全风险需冻结、忘记密码需重置 |
| 功能边界 | 包含:用户列表查询、单个新增、批量导入、编辑、启用/禁用、重置密码、强制修改密码、角色分配(含复制他人配置);不包含:角色本身的创建与授权、组织维护、登录认证流程 |
| 成功结果 | 账号信息与角色绑定关系正确保存,账号可按角色获得对应菜单、操作与数据范围 |

#### 3.1.2 使用条件与权限

| 角色 | 可执行操作 | 数据范围 | 前置条件 |
| ---- | ---------- | -------- | -------- |
| 系统管理员 | 全部操作 | 全部账号 | 已登录且具备本功能菜单权限 |
| 其他角色 | 无 | 无 | 本页面不对其开放菜单与直接访问 |

#### 3.1.3 数据与字段规则

**查询条件:**

| 条件 | 业务含义 | 取值方式或数据来源 | 默认值 | 匹配规则 |
| ---- | -------- | ------------------ | ------ | -------- |
| 所属组织 | 用户归属部门 | 组织架构树选择 | 全部 | 精确匹配 |
| 账号 | 登录账号或姓名关键字 | 手动输入 | 空 | 模糊匹配账号与姓名 |
| 状态 | 账号当前状态 | 枚举:全部、启用、禁用 | 全部 | 精确匹配 |
| 绑定角色 | 账号绑定的角色 | 角色列表选择 | 全部 | 精确匹配,含该角色即命中 |

**列表展示字段:**

| 字段 | 业务含义 | 数据来源 | 格式/口径规则 | 空值处理 |
| ---- | -------- | -------- | ------------- | -------- |
| 账号 | 登录唯一标识 | 本模块 | 创建后不可修改 | 必有值 |
| 姓名 | 用户真实姓名 | 本模块 | — | 必有值 |
| 所属组织 | 归属部门 | 组织架构 | 显示组织全路径(上级/本级) | 必有值 |
| 状态 | 启用/禁用 | 本模块 | 枚举值:启用(可登录)、禁用(禁止登录) | 必有值 |
| 最后登录时间 | 最近一次成功登录 | 登录会话 | yyyy-MM-dd HH:mm:ss | 从未登录显示"—" |
| 绑定角色 | 已绑定的角色集合 | 角色管理 | 多个角色以顿号分隔 | 未绑定显示"—" |
| 备注 | 补充说明 | 本模块 | — | 显示"—" |

**新增/编辑输入字段:**

| 字段 | 必填 | 业务含义与校验 |
| ---- | ---- | -------------- |
| 账号 | 是 | 全局唯一,仅编辑时不可修改;建议字母开头,含字母/数字/下划线,长度≤64 |
| 姓名 | 是 | 长度≤64 |
| 手机号 | 否 | 11位数字且格式校验通过 |
| 邮箱 | 否 | 标准邮箱格式校验通过 |
| 所属组织 | 是 | 从组织树选择一个部门 |
| 账号有效期 | 否 | 起止日期,止期需晚于起期;不填视为长期有效 |
| 绑定角色 | 是 | 从角色列表勾选,可多选 |
| 备注 | 否 | 长度≤200 |
| 状态 | 是 | 枚举值:启用、禁用;新增默认启用 |

#### 3.1.4 业务规则与状态变化

| 规则编号 | 触发条件 | 业务规则 | 数据/状态变化 |
| -------- | -------- | -------- | ------------- |
| U-R1 | 新增账号 | 账号全局唯一性校验,重复则拒绝保存 | 无变化,保留已填内容 |
| U-R2 | 账号有效期到期 | 到期次日账号自动转为禁用,禁止登录 | 状态:启用→禁用(系统触发) |
| U-R3 | 禁用账号 | 禁用后立即失去登录能力,已绑定角色与历史日志保留 | 状态:启用→禁用 |
| U-R4 | 生命周期终结 | 本期不提供账号物理删除,以禁用作为生命周期终结方式 | 无删除操作入口 |
| U-R5 | 角色获得方式 | 用户只能通过绑定角色获得权限,任何页面不提供直接给用户分配功能权限的入口 | 权限随角色绑定即时继承 |
| U-R6 | 批量导入 | 以文件行级校验为准,合法行生效、非法行拒绝并逐行反馈原因 | 成功行写入,失败行不入库 |
| U-R7 | 重置密码 | 管理员重置后账号密码恢复为初始密码,该账号下次登录强制修改密码 | 密码状态:已重置待修改 |

#### 3.1.5 交互流程

**列表查询:**
1. 系统管理员进入账号用户管理页面。
2. 系统默认加载全部账号,按创建时间倒序分页展示。
3. 用户设置查询条件后点击查询,列表按条件刷新;点击重置恢复默认条件。

**新增账号(单个):**
1. 用户点击新增账号。
2. 系统加载组织树与角色列表供选择。
3. 用户填写字段并提交。
4. 处理结果:
   - 成功 → 账号写入并出现在列表 + 提示新增成功 + 可继续编辑或分配角色
   - 失败 → 校验不通过(必填缺失/账号重复/格式错误/有效期起止倒置) → 提示具体原因 + 已填内容保留

**批量导入:**
1. 用户点击批量导入。
2. 系统提供模板下载。
3. 用户上传填写后的文件。
4. 处理结果:
   - 全部合法 → 提示导入成功及条数 + 列表刷新
   - 部分失败 → 提示成功条数与失败行号及原因 + 成功行已生效
   - 文件格式错误 → 整体拒绝,提示重新使用标准模板

**启用/禁用:**
1. 用户在列表对某账号点击禁用(或启用)。
2. 系统弹出二次确认,说明禁用后该账号将无法登录。
3. 确认后状态变更并刷新列表。

**重置密码:**
1. 用户在列表点击重置密码。
2. 系统二次确认。
3. 确认后密码恢复初始值,该账号下次登录被强制引导修改密码。

**角色分配:**
1. 用户在列表点击分配角色。
2. 系统展示该账号当前绑定角色与全部可选角色。
3. 用户勾选一个或多个角色,或选择"复制其他用户配置"并从用户列表选取来源账号,系统自动勾选来源账号的全部角色供确认调整。
4. 提交后绑定关系保存,该账号的菜单、操作与数据范围随角色即时变化。

#### 3.1.6 异常处理

| 异常场景 | 触发条件 | 系统处理 | 用户反馈 | 恢复方式 |
| -------- | -------- | -------- | -------- | -------- |
| 账号重复 | 新增时账号已存在 | 拒绝保存 | 提示账号已存在 | 修改账号后重新提交 |
| 被禁用账号尝试登录 | 禁用状态账号提交登录 | 拦截登录 | 提示账号已禁用,请联系管理员 | 管理员重新启用 |
| 有效期到期自动禁用 | 到期次日系统触发 | 自动禁用 | 登录时提示账号已过期 | 管理员调整有效期并启用 |
| 导入行数据非法 | 必填缺失、账号重复、格式错误 | 该行拒绝,其余行正常处理 | 逐行反馈行号与原因 | 修正文件后重新导入 |
| 角色绑定被清空 | 提交时未勾选任何角色 | 拦截提交 | 提示至少绑定一个角色 | 勾选角色后提交 |

#### 3.1.7 外部依赖

| 依赖模块/服务 | 输入 | 输出 | 调用时机 | 失败处理 |
| ----------- | ---- | ---- | -------- | -------- |
| 组织架构(F02) | 组织选择请求 | 组织树数据 | 新增/编辑与查询时 | 组织加载失败时提示稍后重试,表单不可提交 |
| 角色管理(F03) | 角色列表请求 | 可选角色集合 | 角色分配、查询筛选时 | 同上 |
| 操作日志(平台管理模块) | 权限变更事件 | 日志记录(模块名称:权限管理;业务类型:新增/修改/导入) | 新增、编辑、导入、禁用、重置密码、角色分配完成时 | 异步写入失败不阻断业务,后台补偿 |

### 3.2 F02 组织架构管理

#### 3.2.1 功能目标与范围

| 项目 | 说明 |
| ---- | ---- |
| 功能目标 | 维护平台的部门组织树,作为用户归属管理与数据权限过滤的基础数据 |
| 使用角色 | 系统管理员 |
| 触发条件 | 部门新设、更名、合并、层级调整、撤销时维护组织树;需要查看某部门人员构成时 |
| 功能边界 | 包含:组织树新增、编辑、同级排序、上下级调整、禁用、部门成员查看;不包含:用户的增删改(在F01)、按组织的批量数据授权(在F06) |
| 成功结果 | 组织树结构正确保存,用户归属与数据权限过滤基准随组织变化同步更新 |

#### 3.2.2 使用条件与权限

| 角色 | 可执行操作 | 数据范围 | 前置条件 |
| ---- | ---------- | -------- | -------- |
| 系统管理员 | 组织树全部维护操作、成员查看 | 全部组织 | 已登录且具备本功能菜单权限 |
| 其他角色 | 无 | 无 | 本页面不对其开放 |

#### 3.2.3 数据与字段规则

**组织节点字段:**

| 字段 | 必填 | 业务含义与校验 |
| ---- | ---- | -------------- |
| 组织名称 | 是 | 同一父级下唯一,长度≤64 |
| 上级组织 | 是 | 从现有组织树选择;根节点为平台顶级组织 |
| 排序号 | 否 | 同级展示顺序,数字越小越靠前,默认按创建顺序 |
| 组织状态 | 是 | 枚举值:启用、禁用;新增默认启用 |

**部门成员展示字段:** 账号、姓名、状态、绑定角色(取自F01用户数据,本页面只读)。

#### 3.2.4 业务规则与状态变化

| 规则编号 | 触发条件 | 业务规则 | 数据/状态变化 |
| -------- | -------- | -------- | ------------- |
| O-R1 | 新增/编辑组织 | 同一父级下组织名称唯一,重复拒绝 | 无变化 |
| O-R2 | 禁用组织 | 存在启用状态的下属组织或归属用户为启用状态时,不允许禁用 | 无变化,提示先处理下属与成员 |
| O-R3 | 上下级调整 | 组织节点迁移至新父级后,其全部下属节点随迁 | 树结构变化,成员归属路径变化 |
| O-R4 | 组织与数据权限联动 | 组织变化(更名/迁移/禁用)后,以组织为基准的数据权限过滤随最新组织数据生效 | 数据权限过滤基准更新 |
| O-R5 | 生命周期终结 | 本期不提供组织物理删除,以禁用作为终结方式 | 无删除操作入口 |

#### 3.2.5 交互流程

**组织树维护:**
1. 系统管理员进入组织架构管理页面,左侧展示组织树、右侧展示选中部门的成员列表。
2. 用户选中节点后可执行新增子部门、编辑、排序、调整上级、禁用操作。
3. 用户在弹窗中填写组织信息并提交。
4. 处理结果:
   - 成功 → 组织树刷新 + 提示保存成功 + 受影响用户归属路径同步更新
   - 失败 → 校验不通过(名称同级重复/上级选择为本节点后代形成环路) → 提示原因 + 已填内容保留

**禁用组织:**
1. 用户对节点点击禁用并确认。
2. 系统校验下属组织与成员状态。
3. 处理结果:
   - 校验通过 → 节点转为禁用,不可再被选为用户归属与授权对象
   - 校验不通过 → 提示存在启用下属或启用成员,列明数量,操作取消

**部门成员查看:**
1. 用户在组织树选中某部门。

#### 3.4.2 使用条件与权限

| 角色 | 可执行操作 | 数据范围 | 前置条件 |

| 层级 | 业务含义 | 数据来源 | 可勾选内容 |

#### 3.4.4 业务规则与状态变化

| 规则编号 | 触发条件 | 业务规则 | 数据/状态变化 |
| -------- | -------- | -------- | ------------- |
| A-R1 | 勾选与取消 | 勾选即授权、取消即回收;授权以最终保存的勾选集合为准 | 角色权限集合变化 |
| A-R2 | 父子联动 | 取消菜单授权时其下按钮、接口授权同时失效;按钮/接口不可脱离所属菜单单独生效 | 保存时按最新勾选集合整体覆盖 |
| A-R3 | 授权生效 | 保存后对该角色下全部账号即时生效,账号下一次访问或操作即按新权限校验 | 在线账号权限刷新 |

| A-R5 | 资源禁用联动 | F05禁用某权限资源后,所有角色对该资源的授权即时失效,恢复启用后不自动恢复原授权 | 角色权限集合收缩,需重新授权 |

#### 3.4.5 交互流程

3. 用户勾选或取消权限节点(支持按应用整体勾选),完成后保存。
4. 处理结果:
   - 成功 → 授权集合保存 + 提示成功 + 该角色账号权限即时生效
   - 失败 → 保存异常提示原因 + 勾选状态回退至保存前

#### 3.4.6 异常处理

| -------- | -------- | -------- | -------- | -------- |

### 3.5 F05 权限资源管理

| P-R5 | 批量导入 | 模板下载→上传→行级校验,合法行生效、非法行拒绝并逐行反馈 | 成功行入库 |
| P-R6 | 资源来源 | 以各业务应用上报为主,页面手动录入与批量导入为补充;同一标识重复上报时更新已有资源信息 | 资源信息刷新 |

#### 3.5.5 交互流程

**资源维护:**
1. 系统管理员进入权限资源管理,页面以权限树展示【应用→菜单→按钮/接口】全部资源层级。
2. 用户在应用节点下新增菜单,或在菜单节点下新增按钮/接口,所属应用与父级由节点位置自动确定,无需重复选择层级;编辑时资源类型不可变更。
3. 处理结果:
   - 成功 → 资源入库并在权限树对应节点下出现 + 提示成功
   - 失败 → 标识重复或必填缺失 → 提示原因 + 内容保留

**批量导入:**
1. 用户点击批量导入,下载模板。
2. 上传文件后系统逐行校验。
3. 处理结果:
   - 全部合法 → 提示导入成功条数,资源树刷新
   - 部分失败 → 反馈成功条数与失败行号及原因
   - 模板不符 → 整体拒绝

**权限树全景:**
1. 页面主体即权限树,完整展示【应用→菜单→按钮/接口】层级,支持按应用、名称/标识关键字、状态筛选。
2. 已停用资源在树中以停用标识灰显,不提供独立预览弹窗。

**禁用资源:**
1. 用户对资源点击禁用并二次确认。
2. 确认后资源失效,各角色对该资源的授权即时回收。

#### 3.5.6 异常处理

| 异常场景 | 触发条件 | 系统处理 | 用户反馈 | 恢复方式 |

| 功能目标 | 为角色/用户配置数据可见范围,实现功能权限之外的"能看到哪些数据"控制,支撑多部门、多主体数据隔离 |
| 使用角色 | 系统管理员 |
| 触发条件 | 新角色需要限定数据范围、特定用户需要超出或收窄角色默认范围、需要核查某账号最终可见数据时 |
| 功能边界 | 包含:按角色/用户配置数据范围(预置五档+自定义规则)、生效范围预览;不包含:各业务模块列表页的过滤实现(由业务模块按本模块规则执行) |
| 成功结果 | 配置保存后,目标角色/用户在各业务模块查询列表与统计数据时按数据范围过滤 |

#### 3.6.2 使用条件与权限

| 角色 | 可执行操作 | 数据范围 | 前置条件 |
| ---- | ---------- | -------- | -------- |
| 系统管理员 | 配置任意角色/用户的数据范围、使用预览 | 全部 | 已登录且具备本功能菜单权限 |
| 其他角色 | 无 | 无 | 本页面不对其开放 |

#### 3.6.3 数据与字段规则

**配置对象:** 枚举值:角色(对该角色全部绑定账号生效)、用户(仅对该账号生效)。
**预置数据范围选项:**

| 选项 | 业务含义 |
| ---- | -------- |
| 仅本人数据 | 仅可见自己创建或负责的数据 |
| 本部门数据 | 可见归属本部门的数据 |
| 本部门及下级部门数据 | 可见本部门及其全部下级部门的数据 |
| 指定多个部门 | 可见手工指定的一个或多个部门的数据 |
| 全部数据 | 可见平台全部数据 |

**自定义数据规则字段:**

| 字段 | 必填 | 业务含义与校验 |
| ---- | ---- | -------------- |
| 规则名称 | 是 | 长度≤64 |
| 业务对象 | 是 | 枚举值按业务模块扩展,如车辆、项目、申请单 |
| 过滤方式 | 是 | 枚举值:指定清单可见(仅可见所选对象)、指定清单不可见(排除所选对象) |
| 对象清单 | 是 | 从对应业务对象列表选择,可多选 |

#### 3.6.4 业务规则与状态变化

| 规则编号 | 触发条件 | 业务规则 | 数据/状态变化 |
| -------- | -------- | -------- | ------------- |
| D-R1 | 配置来源优先级 | 用户级配置优先于其角色配置;用户未配置时继承角色配置 | 生效范围判定基准 |
| D-R2 | 多角色合并 | 用户绑定多个角色且均无用户级配置时,数据范围取各角色范围的并集(最大范围) | 生效范围扩大至并集 |
| D-R3 | 组织基准 | "本部门/本部门及下级"以账号当前所属组织为准,组织调整后自动跟随 | 过滤基准随组织变化 |
| D-R4 | 自定义规则叠加 | 自定义规则与预置范围同时配置时,最终可见数据为二者交集 | 生效范围收窄 |
| D-R5 | 配置生效 | 保存后即时生效,目标账号下一次查询即按新范围过滤 | 在线账号数据范围刷新 |
| D-R6 | 超级管理员 | 固定全部数据,不可配置 | 无配置入口 |

#### 3.6.5 交互流程

**配置数据范围:**
1. 系统管理员进入数据权限管理,选择配置对象类型(角色/用户)并定位目标。
2. 系统回显当前生效的数据范围与自定义规则。
3. 用户选择预置范围档位,按需添加、编辑、删除自定义规则,提交保存。
4. 处理结果:
   - 成功 → 配置保存 + 提示成功 + 目标对象数据范围即时生效
   - 失败 → 校验不通过(如指定部门为空、规则清单为空) → 提示原因 + 配置保留

**生效范围预览:**
1. 用户选择某角色或某账号发起预览。
2. 系统计算并展示最终生效的数据范围,包含:生效档位、命中规则、来源说明(来自用户级配置或哪些角色)、涉及的部门与业务对象清单。
3. 用户核对后关闭预览,预览为只读不产生配置变化。

#### 3.6.6 异常处理

| 异常场景 | 触发条件 | 系统处理 | 用户反馈 | 恢复方式 |
| -------- | -------- | -------- | -------- | -------- |
| 指定部门为空 | 选择"指定多个部门"未选部门 | 拒绝保存 | 提示至少选择一个部门 | 补充选择后提交 |
| 规则清单为空 | 自定义规则未选对象 | 拒绝保存 | 提示规则需包含至少一个对象 | 补充对象或删除规则 |
| 配置对象被删除 | 预览/回显时角色已被删除 | 提示对象不存在 | 引导返回重新选择 | 重新选择有效对象 |
| 组织禁用导致基准缺失 | 用户所属组织被禁用 | 该用户数据范围回退为"仅本人数据" | 预览中标注组织失效 | 重新归属组织后恢复 |

| 依赖模块/服务 | 输入 | 输出 | 调用时机 | 失败处理 |
| ----------- | ---- | ---- | -------- | -------- |

## 4. 业务规则汇总

### 4.1 唯一性规则
- 账号全局唯一,创建后不可修改
- 角色编码全局唯一;appId全局唯一
- 权限资源标识/路径全局唯一
- 同一父级下组织名称唯一

### 4.2 删除规则
- 本期账号与组织均不提供物理删除,以禁用终结生命周期,历史数据与日志保留
- 仅自定义角色可删除;被用户绑定时拦截,须先解除全部绑定;删除时其授权与数据范围配置一并清除
- 权限资源与应用不提供删除,以禁用替代;禁用资源在各角色的授权即时失效,重新启用后不自动恢复

### 4.3 状态流转
- 账号:启用→禁用(手动禁用/有效期到期系统自动禁用);禁用→启用(管理员操作)
- 组织:启用→禁用(需先清空启用下属与启用成员);禁用→启用
- 权限资源/应用:启用→禁用(即时回收各角色授权);禁用→启用(不自动恢复授权)
- 角色:无启用/禁用状态,仅有系统内置/自定义类型区分与删除终结

### 4.4 字段联动规则

| 触发字段 | 触发条件 | 联动行为 |
| -------- | -------- | -------- |
| 用户所属组织 | 变更归属部门 | 用户列表组织显示、"本部门"类数据权限过滤基准同步变化 |
| 用户绑定角色 | 增减角色 | 账号菜单、操作、数据范围即时重算 |
| 权限资源状态 | 禁用 | 授权树隐藏该资源,各角色授权即时失效 |
| 账号有效期 | 到期次日 | 账号自动禁用 |
| 角色删除 | 删除完成 | 其全部绑定关系解除,授权与数据范围配置清除 |

### 4.5 计算规则
- 关联用户数量=绑定该角色且账号状态为启用的账号数
- 用户最终数据范围:存在用户级配置时以用户级为准;否则取全部绑定角色范围的并集;自定义规则与预置范围取交集后生效
- 数据范围档位包含关系:全部>本部门及下级>本部门>仅本人,并集取参与角色中最大档位

### 4.6 校验规则

**表单校验:**

| 校验项 | 校验内容 | 失败反馈 |
| ------ | -------- | -------- |
| 账号/角色编码/appId格式 | 字母开头,仅含字母数字下划线,长度≤64 | 提示格式要求 |
| 手机号 | 11位数字 | 提示格式错误 |
| 邮箱 | 标准邮箱格式 | 提示格式错误 |
| 账号有效期 | 止期晚于起期 | 提示时间范围无效 |
| 组织上级选择 | 不得选择本节点及其后代 | 提示不能形成环路 |

**导入校验:** 模板列完整性、必填非空、格式合法、唯一性不冲突;任一行失败仅拒绝该行,不影响其余行。

### 4.7 审批权限规则

| 操作 | 权限范围说明 |
| ---- | ------------ |
| 本模块全部页面与操作 | 仅系统管理员可访问与执行,其他角色不开放菜单与直接访问 |
| 系统内置角色维护 | 任何人不可编辑、删除、调整授权;超级管理员固定全部权限与全部数据 |
| 危险操作二次确认 | 禁用账号、禁用组织、重置密码、删除角色、禁用资源、移除角色用户均需二次确认后执行 |

### 4.8 编号生成规则

| 规则项 | 说明 |
| ------ | ---- |
| appId | 由管理员按应用接入规范分配,全局唯一,建议"应用英文缩写+用途"如`monitor`(车辆状态监控) |
| 角色编码 | 管理员自定义或复制角色时填写,全局唯一,如`enterprise`(企业用户)、`readonly`(只读观察员) |
| 权限资源标识 | 菜单为页面路由、按钮为按钮标识、接口为API路径,由业务应用上报或管理员录入,全局唯一 |

### 4.9 变更日志记录规则
- 记录范围:账号增改/导入/禁用/重置密码/角色分配、组织增改/迁移/禁用、角色增改删/分配用户、角色授权保存、权限资源增改/导入/禁用、数据权限配置保存
- 记录字段:模块名称统一为"权限管理",业务类型按平台操作日志通用分类(新增/修改/删除/导入归入新增或修改),描述包含目标对象与变化概要
- 排列规则:按操作时间倒序,支持在操作日志中按模块名称"权限管理"筛选
- 不可篡改:日志由统一日志服务异步写入,页面不提供修改入口
